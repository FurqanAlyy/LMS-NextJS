# Local seed media

Run `npm run seed:assets` to download these files into this directory before running the database seed. The seed uploads **these local files** to your Cloudinary account. Images use public delivery; the sample video uses authenticated delivery.

Images are sourced from Unsplash, under the [Unsplash License](https://unsplash.com/license):

- `web-development.jpg`: https://images.unsplash.com/photo-1498050108023-c5249f4df085
- `design.jpg`: https://images.unsplash.com/photo-1558655146-9f40138edfeb
- `javascript.jpg`: https://images.unsplash.com/photo-1515879218367-8466d910aaa4
- `workspace.jpg`: https://images.unsplash.com/photo-1496181133206-80ce9b88a853

`sample-lesson.mp4` is the [MDN flower video](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4), provided in MDN’s CC0 media directory. It is a short playback demonstration, **not instructional course content**. All seeded lesson descriptions explicitly identify this. Replace it with your own teaching material before offering real courses.

The seed is additive and does not delete records or overwrite existing course content. Keep these media files with the project so the seed is reproducible.
